## 🚀 Summary
Advanced Scene Switcher Pro for Windows is a plugin that gives OBS Studio the ability to switch scenes on its own. You configure conditions — a running game, a media state, a schedule, a hotkey — and the plugin fires the matching scene change automatically. For streamers and creators who want a smoother show, this free advanced scene switcher OBS plugin removes the constant manual clicking from live production.

## ✨ Feature Set
1. Trigger scene changes from active windows, running processes, and idle time 🪟
2. Build layered automation with a full condition-and-action macro editor 🧩
3. Sequence transitions with delays and cooldowns for clean pacing ⏱️
4. Mix automatic rules with manual hotkey switching whenever you need 🎛️
5. Enjoy a free, open-source plugin you can inspect and extend 🆓

## 📥 Installation Steps
1. Hit the **Download** button above to grab the free Advanced Scene Switcher OBS plugin for Windows.
2. Close OBS Studio and run the installer (or copy the plugin into the OBS Studio plugins folder), following the prompts.
3. Open OBS Studio and go to **Tools → Advanced Scene Switcher**, where the plugin is now listed in the menu.

## 🎯 Getting Started
1. Open OBS Studio with your usual scene collection loaded.
2. Choose **Tools → Advanced Scene Switcher** from the menu bar.
3. Set up a condition and link it to the scene you want it to activate.
4. Enable the switcher, then trigger the condition to see the scene change happen automatically.

## ❓ FAQ
**Is Advanced Scene Switcher Pro free?**
Yes — it is a free, open-source plugin, so you can download and use the OBS advanced scene switcher without any cost.

**Which versions of Windows are supported?**
It runs on 64-bit Windows 10 and Windows 11 wherever a compatible OBS Studio version is installed.

**Is my data secure?**
Your automation rules are stored in your local OBS Studio configuration, and the plugin runs on your own PC, so it does not send your setup to any external service on its own.
